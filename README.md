# go-color

一堆文本要处理，开编辑器点来点去太慢，命令行一把梭最省事。

颜色格式互转 + WCAG 对比度检查。

调 CSS、画图、做终端配色时，经常在 `#rrggbb` / `rgb()` / `hsl()` 之间倒腾，还得确认白字配这个背景到底看不看得清。这个工具一次性把这两件事做了，零依赖，只用 Go 标准库。

## 安装

```bash
go build -o go-color .
```

## 用法

把任意颜色喂进去，三种写法一起给你：

```bash
go-color "#ff0000"
# 或
go-color "rgb(0, 128, 255)"
# 或
go-color "hsl(120, 100%, 50%)"
```

输出：

```
#ff0000
  HEX #ff0000
  RGB  rgb(255, 0, 0)
  HSL  hsl(0, 100%, 50%)
```

一次也能传多个颜色。

### 对比度

```bash
go-color contrast <前景> <背景>
```

按 WCAG 2.x 公式算对比度，并直接告诉你能不能达标：

```bash
go-color contrast "#fff" "#000"
# 对比度 21.00:1
# AAA 级（最好，正文也够用）
```

等级划分：≥7 是 AAA（正文也够用），≥4.5 是 AA（正文达标），≥3 是 AA 大字号（仅大标题够用），再低就不达标了。

### 最佳前景色

给定一个背景色，告诉你黑字还是白字更清楚：

```bash
go-color best "#336699"
# 在 #336699 上用 #ffffff 最清楚（对比度 5.41:1）
```

## 支持的输入

- `#rgb`（自动展开成 `#rrggbb`）
- `#rrggbb`
- `rgb(r, g, b)`
- `hsl(h, s%, l%)`（百分号带不带都行，色相超出 0-360 会自动卷绕）

## 已知细节

- HSL 转 RGB 再转回 HSL 可能有 ±1 的取整误差，这是 8 位色深的固有限制
- 对比度算法用的是 WCAG 2.x 的相对亮度公式，不是简单的灰度差
